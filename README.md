# Linear Regression Visual Lab

**Live site:** https://snsie.github.io/linear-reg/

An interactive React app to explore linear regression

1. Meet the data
2. Find the line
3. Why least squares?
4. Stretch the spread (how the SDs of x and y set the slope)
5. Diagnose the model
6. Make a prediction
7. Bend the line (linear vs nonlinear regression)

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Production build

```powershell
npm.cmd run build
```

The production output is written to `dist/`.
