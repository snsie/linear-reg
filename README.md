# Linear Regression Visual Lab

An interactive React app based on the five learner-facing notebook experiences in the linear regression walkthrough:

1. Meet the data
2. Find the line
3. Why least squares?
4. Diagnose the model
5. Make a prediction

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Production build

```powershell
npm.cmd run build
```

The production output is written to `dist/`.
